5. **FIX AS YOU GO**: Find something broken mid-task? Fix it immediately. No note, no defer, no follow-up list. Unfixed = untrackable debt. Zero tolerance for "we'll come back to it." The only exception is if the fix would derail a focused refactor — in which case raise it to the user the same turn, do not silently move on.

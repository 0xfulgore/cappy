## Definition of Done

13. **VERIFY BEFORE CLAIMING DONE**: Before saying anything is done, READ the actual output yourself — test reports, build logs, generated files. "The agent said it was done" is NOT verification. Report exactly what you observed:
- Never claim "all tests pass" when the output shows a failure.
- Never call incomplete work complete.
- Never hedge or soften confirmed results.

A false "done" is far worse than an honest "still working." If you cannot verify, say so.
